# ChatGPT desktop setup

Open https://intent-handoff.joyhuiqi.workers.dev as a **top-level tab** in ChatGPT desktop.

- Use GPT-5.6 Sol or GPT-5.6 Terra.
- Enable **Settings → Browser → Permissions → Site tools**.
- In the address bar, open **Site tools → Available site tools**.
- Confirm these tools appear: `get_handoff_context`, `start_handoff`, `report_handoff_progress`, and `submit_handoff_result`.

Connect a page, click a target, write the instruction, then copy the popup message into the current Codex conversation. Keep the handoff tab open while Codex works.
