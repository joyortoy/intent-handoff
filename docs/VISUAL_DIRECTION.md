# JoyRelay visual direction

## Product intent

The user feels like they are booking a hotel, not configuring an AI.

## Emotional target

I want to go there.

## Visual target

Premium Tokyo travel planning: warm paper, deep navy type, cream surfaces, one blue action accent, large destination photography.

## Interaction target

Every click visibly improves the shared trip on the right.

## Proof target

Muted-audio 16:9 recording can show: choose trip → hand off → match → $200→$150 → updated match.

## Component grammar

- Hero: full-bleed Tokyo photograph, serif headline, white search card overlapping the fold.
- Search: airport-style FROM / TO / DATES fields.
- Preferences: four equal “what matters” cards, not a form stack.
- Trip panel: white editorial card, navy heading, terracotta-free blue CTA.
- Result: hotel photograph, Best match badge, rejected option as a quiet comparison.
- Debug: only `?debug=true`.
